# Sequential implementation plan

1. **Foundation (complete):** monorepo, SQLite domain, seed, API, navigation, season and match views.
2. **Spatial replay (MVP):** procedural metric pitch, player and ball primitives, trajectories and camera presets.
3. **Film workspace (MVP):** split workspace, common clock, annotations, scrubbing and edit-mode affordances. Next: persisted draggable orthographic keyframes.
4. **Corners (MVP):** specialized schema, descriptive service and reconstructed demonstration. Next: API-driven filters and overlay calculations.
5. **Penalties (MVP):** continuous goal coordinates, shootout order, shrinkage service, goal map and specialized camera workflow. Next: posterior quantiles via scipy and clip filters.
6. **Reporting (partial):** analyst findings and descriptive opponent language. Next: report composer, clip attachment and print layout.

The governing product boundary is evidence rather than automated tactical advice. Statistical results remain distinct from analyst interpretation.
